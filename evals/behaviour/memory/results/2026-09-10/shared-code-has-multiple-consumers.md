Before changing the shared normalization rule, the change must be treated as a cross-product semantic and contract change, not as an isolated library edit. Nothing currently authorizes implementation or approval.

Conclusions

- Alpha and beta are both declared consumers of one shared normalization function. `PLATFORM.md` §“Shared rules” says the library is used by both products, and [DEC-001](</tmp/framework-memory-phase9-batch-20260910/trials/shared-code-has-multiple-consumers/project/decisions/DEC-001-shared-rule.md:22>) establishes that they reuse one pure function.
- The existing semantics are part of an inter-product data contract: the normalized value must be a non-null string that is stripped and case-folded. Changing that meaning requires a new major version of DC-001 and notice to beta under [DC-001 §Breaking change policy](</tmp/framework-memory-phase9-batch-20260910/trials/shared-code-has-multiple-consumers/project/products/alpha/contracts/DC-001-response.md:27>).
- A semantic change requires tests in both consumers under [DEC-001 §Consequences](</tmp/framework-memory-phase9-batch-20260910/trials/shared-code-has-multiple-consumers/project/decisions/DEC-001-shared-rule.md:24>). The available tests are narrow ASCII examples and do not establish compatibility for whitespace variants, Unicode case folding, empty strings, repeated normalization, invalid values, or any proposed new semantics.
- The function must remain pure, and tenant state must not be cached. Adding state or caching would conflict with [DEC-001 §Decision](</tmp/framework-memory-phase9-batch-20260910/trials/shared-code-has-multiple-consumers/project/decisions/DEC-001-shared-rule.md:22>). A tenant-keyed mutable cache was expressly rejected for lack of measured need in §Alternatives.
- If alpha and beta now need incompatible semantics, the sharing decision itself must be revisited under [DEC-001 §Review condition](</tmp/framework-memory-phase9-batch-20260910/trials/shared-code-has-multiple-consumers/project/decisions/DEC-001-shared-rule.md:29>). DEC-001 is marked immutable, so it must not simply be edited.

Under [AGENTS.md §Fixture control plane](</tmp/framework-memory-phase9-batch-20260910/trials/shared-code-has-multiple-consumers/project/AGENTS.md:16>), only such a contract can authorize implementation. The empty root, platform, alpha, and beta open registers neither authorize a change nor prove that no undiscovered impact exists.
