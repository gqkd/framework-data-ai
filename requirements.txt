# Three dependencies, and the second and third are decisions worth knowing about.
#
# `jsonschema` is what lets the front matter check live in the generated schemas instead
# of being reimplemented in Python. One enforcement path rather than two: a schema an
# editor reads and a schema CI enforces cannot disagree if they are the same file.

pyyaml>=6.0
jsonschema>=4.18

# `python-pptx` is the third, and it is here rather than optional so that CI renders what
# the `presentation` skill renders. An optional import would have let the self check print
# `ok` over a renderer it never ran, which is the failure `_extract_keeps_provenance` was
# written against. Only `skills/presentation/scripts/render.py` imports it, and only to
# render: checking an outline needs PyYAML alone.
python-pptx>=1.0
